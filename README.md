# Codex Project Context

This package transfers the useful historical context from the ChatGPT work.

- `AGENTS.md` — short persistent context and user preferences.
- `websites/` — website project knowledge.
- `travian/` — Travian project knowledge.

This ZIP is context/documentation, not a deployable website package.

For the website repository, use only the website-related files. For the Travian repository, use only the Travian-related files. Do not upload the ZIP itself as a website.

Recommended: put `AGENTS.md` at the root of each repository Codex actively manages and copy the relevant project documents into that repository's `docs/` folder.
