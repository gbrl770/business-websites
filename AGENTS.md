# Codex Project Context

This repository contains the user's website projects and related project knowledge.

## User preferences
- Hebrew is the default communication language.
- Prefer concise, precise, practical instructions.
- For implementation, deliver finished work rather than asking for tiny test cycles.
- Never invent business details, phone numbers, prices, reviews, credentials, or facts.
- Preserve completed work unless a requested change requires modifying it.
- Perform appropriate QA before declaring work finished.

## Website standards
- Professional, responsive, finished appearance on desktop and mobile.
- Working navigation and actions.
- Real photographs when real images are requested; never silently substitute AI images.
- Do not make website images clickable unless explicitly requested.
- No visible image-source notes/captions when the user asks for a clean presentation.
- Do not present stock/placeholder images as the business owner's own work.
- GitHub Pages projects normally require a top-level index.html in their project folder.
- Validate JavaScript and final file structure before delivery.

This is project context, not a restriction on Codex's reasoning or technical choices.
